## Selected work

### [Faultline](https://github.com/raimbekalish/faultline) — Make failures measurable

`Go` · `OpenTelemetry` · `SQLite` · `React` · `Docker`

A local-first reliability lab for an isolated sample microservice system. Inject controlled dependency latency, observe failures and recovery, inspect persisted runs in a dashboard, and export portable `.flb` evidence for offline verification and comparison.

[Repository](https://github.com/raimbekalish/faultline) · [Watch the 80-second demo](https://github.com/user-attachments/assets/4fcc2604-4000-4d26-87f4-30af3e5577cc)

### [ReproSeed](https://github.com/raimbekalish/reproseed) — Turn browser failures into regression tests

`TypeScript` · `Node.js` · `Playwright`

A local CLI that removes unnecessary steps from a reproducible browser failure, verifies the remaining sequence with fresh replays, and exports a Playwright regression test. Designed for explicitly integrated, authorized loopback test apps.

[Repository](https://github.com/raimbekalish/reproseed)

### R-Finance — Computer vision for vehicle validation

`Python` · `FastAPI` · `YOLO` · `Docker` · `Kubernetes`

Worked on a vehicle-photo validation backend for an auto-collateral lending workflow, including passenger-car checks, multi-image consistency checks, and a containerized development deployment. The code is private; the public [case study](https://callmeraim.dev/#selected-work) describes the work without sharing internal data.

### [Poly Predictor Kit](https://github.com/raimbekalish/Poly_Predictor_Kit) — AI-assisted market analysis

`Python` · `Flask` · `scikit-learn` · `Gemini` · `JavaScript`

Team-built Chrome extension combining prediction-market summaries, a TF-IDF/logistic-regression comment classifier, and risk signals.

**1st place, Polymarket Track — QuackHacks.**
